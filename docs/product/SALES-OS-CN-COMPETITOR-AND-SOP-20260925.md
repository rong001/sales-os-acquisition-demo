## Section 1 — 竞品地图（至少 8 家，分档）

### 分档说明

| 档位 | 含义 | 对 Sales OS 的意义 |
|------|------|-------------------|
| **A. 中大型 PaaS CRM** | 线索→回款全链路 + 定制/行业包 | 功能天花板与「老板想要的完整度」标杆；不宜正面硬拼 PaaS |
| **B. 成长型/电销一体 CRM** | 获客+外呼+公海+AI 初筛 | **与 Sales OS 客群最重叠**；可学电销闭环与公海规则 |
| **C. 生态/SCRM 层** | 企微/钉钉侧边栏、活码、会话存档 | 中国销售「微信中枢」刚需；Sales OS 必须预留官方 API 接入位 |
| **D. 外呼/工作手机层** | 线路、录音、脱敏拨号、质检 | 电销场景强威胁；Sales OS 宜「对接」而非自建线路 |
| **E. 国际对照（非主竞品）** | Salesforce / HubSpot | 说明中国落地差异，避免照搬欧美字段模型 |

### 1.5 腾讯企点 / 企业微信 + SCRM 生态（C 档·生态层）

| 维度 | 内容 |
|------|------|
| **定位** | 不是单一 CRM，而是**中国销售沟通中枢**：企微会话 + 活码/SOP/群运营 + 会话存档分析；企点「企微互动」等官方能力 + 探马/微伴等第三方 |
| **核心模块（生态共性）** | 员工/渠道活码、欢迎语、标签、侧边栏、群发/朋友圈任务、客户/群 SOP、会话存档与质检、裂变、部分电商订单回流 |
| **代表产品简述** | **企点企微互动**：获客活码、私域运营、素材/SOP、会话分析（腾讯云文档）。**探马**：偏销售管理+B2B 企业客户模式、线索分配、会话行为质检；公开渠道称标准版约 **¥1080/账号/年**（10 账号起等条件——区间来源）。**微伴助手**：活码、画像、群 SOP、流失提醒、营销玩法，偏零售/教育私域。 |

### 1.8 Salesforce / HubSpot 在中国落地差异（E 档·对照）

| 维度 | Salesforce | HubSpot |
|------|-------------|---------|
| **中国落地** | 有阿里云等本地化叙事；实施重、成本高；企微连接器可用性需核实当期政策 | 强在营销自动化/内容/邮件；**企微/钉钉非原生中枢**，多靠第三方 |
| **与本土差异** | 字段/流程欧美项目制；中文电销公海、微信侧边栏、广告线索回传体验弱于本土 | 适合出海/内容获客团队；纯国内电销团队采用率通常低于 EC/纷享等 |
| **对 Sales OS** | **非主竞品**；对照结论是：中国销售公司要的是「微信动词 + 公海 + 能打能录 + 老板三屏」，不是先上复杂 Opportunity Stage 模型 |

## Section 2 — 中国销售公司真实使用习惯（用户视角）

### 2.1 角色与日常

| 角色 | 日常关心什么 | 系统期望（一句话） |
|------|--------------|-------------------|
| **老板/销售总监** | 今天打了多少、成交多少、回款有没有风险、谁在摸鱼 | 手机三屏：今日待办 / 团队漏斗 / 回款风险 |
| **销售经理** | 线索够不够、有没有囤单、下周能成交几个 | 分配、回收、陪访、阶段看板、抽查录音 |
| **销售员（面销/网销）** | 客户微信在不在、下次跟什么、别被抢走 | 私海列表短、跟进一键、提醒准 |
| **电销坐席** | 接通率、话术、班次任务量、别封号 | 一键外呼、弹屏、结果三选一（有意向/再跟/无效） |
| **客服** | 售后问题、转介绍、别丢单 | 工单轻量、关联原 LeadCase |
| **市场投放** | 渠道 ROI、表单质量、回传 | 来源字段诚实、重复线索可见、落地页/广告 ID |
| **售前** | 预约演示、材料版本 | 预约状态、演示结论回写 |
| **财务回款** | 合同额、已回、逾期 | 合同-回款计划-实收最小闭环 |
| **运营管理员** | 账号权限、公海规则、导入模板 | RBAC、规则配置、审计日志 |

### 2.2 工具习惯（中国特色）

1. **微信 / 企微 / 钉钉是中枢**，CRM 是「班长要求填的表」——必须降低二次录入，最好侧边栏写跟进。  
2. **Excel 导入** 仍是获客主流：投放表、展会表、购买名单；要有模板、去重、来源标记。  
3. **公海 / 私海**：资源稀缺文化；规则不透明=内耗；领取上限、保护期、未跟进回收是「政治正确」功能。  
4. **电话 + 录音**：电销团队刚需；无录音则质检与纠纷无依据。  
5. **跟进记录要短**：偏好「沟通要点 + 下次时间 + 意向标签」，厌恶长表单。  
6. **老板要手机看板**：不是 BI 宇宙，是三张卡。  
7. **怕复杂字段**：上线失败主因常是「字段太多像 ERP」。

### 2.3 高频痛点

| 痛点 | 表现 | 系统应对方向 |
|------|------|--------------|
| 重复录入 | 微信聊完再回电脑填 CRM | 侧边栏/快捷跟进、通话自动小结 |
| 线索抢夺 | 撞单、私藏、离职带走 | 查重、撞单规则、号码脱敏、审计 |

## Section 5 — 产品优化优先级（AI 产品经理视角）

### 设计原则「符合中国思维」

1. **渐进披露**：默认 8 个字段能干活；高级字段折叠。  
2. **少字段先干活**：先有意向/再跟/无效，再谈商机金额。  
3. **微信习惯动词**：跟进、甩单、捞公海、加微、回款，少用英文 CRM 黑话。  
4. **公海透明**：规则只读可见，回收可预期。  
5. **老板三屏**：今日待办｜团队漏斗｜回款风险。  
6. **官方 API only**：企微、云呼、电子签均走正规开放平台。  
7. **证据优先**：录音、同意、来源、审计 —— Sales OS 已有诚实基因，继续放大。

### P0（本季度必须有体感）

| 项 | 为什么 | 验收标准 |
|----|--------|----------|
| **P0-1 公海/私海规则引擎** | 中国销售政治刚需；无则无法替代 Excel+群抢单 | 可配置上限/保护期/N 天回收；回收通知；规则页销售可见；审计日志 |
| **P0-2 极简跟进+强制下次时间** | 提升填写率 | 跟进≤3 控件；无下次时间不可保存；今日待办按时间排序 |
| **P0-3 通话对接（官方）+录音挂案件** | 电销证据链 | 一键拨号（供应商沙箱）；通话结束回写时长/结果；可播放录音；MOCK 与 REAL 诚实开关保留 |
| **P0-4 老板手机三屏** | 付费决策人体验 | 移动端或企微工作台：待办/漏斗/逾期回款（回款可先用「成交未建回款计划」占位） |
| **P0-5 批量导入体验打磨** | 市场日常 | 模板下载；失败行导出；来源必填；合并提示可读 |

### P1（下季度形成差异）

| 项 | 为什么 | 验收标准 |
|----|--------|----------|
| **P1-1 企微侧边栏（官方）** | 消灭二次录入 | 侧边栏打开 LeadCase；写跟进；打标签；来源只读 |
| **P1-2 合同最小对象** | won≠可财务 | 合同金额/附件/状态；关联 LeadCase |
| **P1-3 回款计划+实收** | 老板第三屏有数 | 计划 vs 已回；逾期列表 |
| **P1-4 外呼任务包** | 电销班次 | 经理建任务→坐席队列→完成率 |
| **P1-5 话术库+优秀录音** | 知识离开人脑 | 场景话术 CRUD；录音标星；侧边栏可点 |

### P2（可排期/可集成）

| 项 | 为什么 | 验收标准 |
|----|--------|----------|
| P2-1 AI 跟进摘要/下一步建议 | 学销售易/EC，但约束幻觉 | 基于时间轴生成摘要；人工确认后写入 |
| P2-2 AI 初筛外呼（官方合规） | 成本战 | 仅沙箱；结果进公海标签；可关 |
| P2-3 会话质检（企微存档官方） | 飞单/敏感词 | 抽检队列 |
| P2-4 提成规则 | 绩效 | 导出或简单比例 |
| P2-5 行业插件包 | 制造/教培等 | 字段包+话术包一键启用 |
